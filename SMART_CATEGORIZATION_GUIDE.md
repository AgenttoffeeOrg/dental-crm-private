## 🧠 **How Auto-Categorization Works**

### **The Rules:**

| If Deal Has... | Goes To... | Reason |
|----------------|------------|--------|
| **£5,000+ value** OR implants, full mouth | 💎 High-Value Treatment | Premium treatments |
| **Emergency keywords** (pain, bleeding, urgent) | 🚨 Emergency Treatment | Urgent care needed |
| **Invisalign, braces, orthodontic** | 🦷 Orthodontics | Long-term alignment |
| **Veneers, whitening, cosmetic** | ✨ Cosmetic Dentistry | Aesthetic procedures |
| **Referral keywords** or referral source | 🤝 Referral Network | From other dentists |
| **Checkup, cleaning** OR <£500 | 👥 General Practice | Routine care |

## 🚀 **How to Use**

### **View All Deals:**

1. Go to **Pipeline** page
2. Click the pipeline dropdown (top left)
3. Select **"📊 All Deals"**
4. See every deal from every pipeline in table view

### **Auto-Categorize Existing Deals:**

1. Make sure you're in **"All Deals"** view
2. Click the purple **"Auto-Categorize Deals"** button
3. Watch as deals move to correct pipelines!
4. Get success message showing how many were moved

### **Create Deals with Smart Suggestions:**

1. Click **"+ New Deal"**
2. Enter deal title (e.g., "John - Dental Implants")
3. Add treatment tag: Type "implants" and press Enter
4. 💡 **System automatically suggests** "High-Value Treatment" pipeline!
5. Adjust if needed, or accept the suggestion
6. Create deal - it goes to the right pipeline!

When you click "Auto-Categorize Deals":

   - Evaluates deal value
   - Looks at source

2. **Determines best pipeline:**
   - Matches against treatment patterns
   - Considers value thresholds
   - Checks urgency indicators
   - Calculates confidence score

3. **Moves the deal:**
   - Changes pipeline

   - Any errors

## 🔧 **Technical Details**

### **Categorization Logic:**

1. **Emergency Check** (Highest Priority)
   - Scans for urgent keywords
   - If found → Emergency pipeline
   - Confidence: 95%

2. **High-Value Check**
   - Value ≥ £5,000 OR implant keywords
   - If match → High-Value pipeline
   - Confidence: 85-90%

3. **Specialty Checks**
   - Orthodontics keywords → Orthodontics
   - Cosmetic keywords → Cosmetic Dentistry
   - Referral indicators → Referral Network
   - Confidence: 80-90%

4. **Default**
   - Everything else → General Practice
   - Confidence: 60%
