# Glossary

## Terms

**Contact** - A person in your database (patient or lead)

**Deal** - A potential or confirmed treatment opportunity

**Pipeline** - A customizable workflow for tracking deals

**Stage** - A step in a pipeline (e.g., "Consultation", "Proposal")

**Task** - An action item assigned to a team member

**Activity** - A logged interaction (call, email, meeting, etc.)

**Campaign** - A marketing message sent to multiple contacts

**Segment** - A filtered group of contacts

**Template** - A pre-written message for quick sending

**Journey** - An automated series of marketing messages

**Attribution** - Tracking which marketing efforts led to deals

**CAC** - Customer Acquisition Cost

**LTV** - Lifetime Value of a customer

**ROI** - Return on Investment

**Conversion Rate** - Percentage of leads that become patients

**Pipeline Velocity** - Average time to close deals

**Win Rate** - Percentage of deals won

**MRR** - Monthly Recurring Revenue

**ARR** - Annual Recurring Revenue

**Churn** - Rate at which patients stop returning

**Cohort** - Group of patients acquired in same time period

## Technical Terms

**API** - Application Programming Interface

**Webhook** - Automated message sent when event occurs

**OAuth** - Authentication protocol

**2FA** - Two-Factor Authentication

**SSO** - Single Sign-On

**RLS** - Row-Level Security

**UUID** - Unique identifier

**JWT** - JSON Web Token

**SMTP** - Email protocol

**CSV** - Comma-Separated Values (file format)

**PWA** - Progressive Web App

**CDN** - Content Delivery Network

**CRM** - Customer Relationship Management

**PMS** - Practice Management Software

**EMR** - Electronic Medical Records

**HIPAA** - Health Insurance Portability and Accountability Act

**GDPR** - General Data Protection Regulation

**UI** - User Interface
