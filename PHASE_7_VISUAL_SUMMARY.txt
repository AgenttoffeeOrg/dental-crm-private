        [ 🦷 Dental Implants × ]
                    ↓

                    ↓

        Pipeline * [ ✨ Suggested ℹ️ ]

                    ↓
                    
Step 7: User can accept or override
        If user tries to change → Shows confirmation modal
        If user accepts → Deal created with suggested pipeline
