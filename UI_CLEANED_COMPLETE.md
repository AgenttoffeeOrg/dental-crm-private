## 🎯 HOW TO USE

### **Quick Start:**

**1. Create a Custom Role**
```
Settings → 🛡️ Roles → Create Role
Name: "Treatment Coordinator"
Icon: 🩺
Color: Purple
→ Save
→ Click "Permissions" → Toggle what they can do
```

**2. Invite Team Member**
```
Settings → 👥 Team → Invite Team Member
Email: colleague@practice.com
Role: Treatment Coordinator
→ Send → Copy link
```

**3. View Activity**
```
Settings → 📰 Activity
See who did what, when
```

**4. Check Audit Trail**
```
Settings → 🔒 Audit
See every action with before/after states
```

**5. Configure Deals**
```
Settings → 💼 Deals
Set required fields, value thresholds, rules
```
