│ 📊 ROUTING DECISION MATRIX                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

  forceManual  enableAuto  targetPipeline  Result
  ───────────────────────────────────────────────────────────
  true         any         provided        → Manual Override
                                             Engine NOT called
                                             Use targetPipelineId

  false        true        provided        → Auto Routing
                                             Engine called
                                             Pass as user_override

  false        true        undefined       → Auto Routing
                                             Engine called
                                             Pure tag-based routing

  false        false       provided        → Routing Disabled
                                             Engine NOT called
                                             Use targetPipelineId

  false        false       undefined       → ERROR
                                             Must specify pipeline
                                             when routing disabled
