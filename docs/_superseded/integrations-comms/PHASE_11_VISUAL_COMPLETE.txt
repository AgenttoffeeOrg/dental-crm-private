┌──────────────────────────────────────────────────────────────────────────────┐
│ 🎯 ROUTING METHODS SUPPORTED                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

  1. ⭐ User Override (Not used in PMS)
     Priority: HIGHEST
     When: Manual pipeline specified
     PMS: Not applicable (automated)

  2. 🏷️ Tag Mapping
     Priority: HIGH
     When: Extracted tags match configured mappings
     Example: "Dental Implants" → High-Value Pipeline
     ✅ Most common for PMS deals

  3. 🤖 AI Keyword Matching
     Priority: MEDIUM
     When: Keywords in treatment text match tag keywords
     Example: "implant" in description → Dental Implants tag
     ✅ Fallback when no procedure codes

  4. 📦 Unsorted Fallback
     Priority: LOWEST
     When: No tags or no matches
     Example: Generic treatment → Unsorted Pipeline
     ✅ Ensures no deal is lost
