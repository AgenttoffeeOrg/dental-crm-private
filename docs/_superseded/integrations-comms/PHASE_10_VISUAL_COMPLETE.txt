┌──────────────────────────────────────────────────────────────────────────────┐
│ 📊 BEFORE vs AFTER COMPARISON                                                │
└──────────────────────────────────────────────────────────────────────────────┘

  BEFORE (Hardcoded):
  ┌────────────────────────────────────────┐
  │ Webhook → Contact → Pipeline Query     │
  │                      (hardcoded)       │
  │                           ↓            │
  │                    Default Pipeline    │
  │                           ↓            │
  │                      Create Deal       │
  └────────────────────────────────────────┘

  AFTER (Dynamic):
  ┌────────────────────────────────────────┐
  │ Webhook → Contact → Tag Extraction     │
  │                      (AI or explicit)  │
  │                           ↓            │
  │                    Routing Engine      │
  │                      (smart logic)     │
  │                           ↓            │
  │                    Routed Pipeline     │
  │                           ↓            │
  │                    Create Deal         │
  │                      + Log Routing     │
  └────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🎯 ROUTING METHODS SUPPORTED                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

  1. ⭐ User Override
     Priority: HIGHEST
     When: Manual pipeline specified in dealRules
     Example: "Always route forms to Sales Pipeline"

  2. 🏷️ Tag Mapping
     Priority: HIGH
     When: Tags match configured mappings
     Example: "Dental Implants" → High-Value Pipeline

  3. 🤖 AI Keyword Matching
     Priority: MEDIUM
     When: Keywords in text match tag keywords
     Example: "implant" in description → Dental Implants tag

  4. 📦 Unsorted Fallback
     Priority: LOWEST
     When: No tags or no matches
     Example: General inquiry → Unsorted Pipeline
