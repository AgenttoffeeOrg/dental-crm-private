## 🎯 **HOW TO USE**

### **1. Run Migration:**
```sql
-- In Supabase SQL Editor:
-- Paste: supabase/sql/64_marketing_feature_flags.sql
-- Click Run
```

### **2. Access Settings:**
```
Navigate to: /settings/marketing
```

### **3. Enable Features:**
- Go to "Features" tab
- Toggle switches for features you want
- Features above your plan show "Upgrade" button
- Can start 14-day trials for Pro/Enterprise features

### **4. Use Feature Gates in Code:**
```typescript
import { FeatureGate } from '@/components/marketing/feature-gate'

// Wrap any premium component
<FeatureGate featureKey="click_heatmaps">
  <HeatmapViewer campaignId={id} />
</FeatureGate>
```
