## 🎯 Quick Start (5 Minutes)

### Step 1: Environment Variables (2 min)
1. Copy `.env.example` to `.env.local`
2. Add your Supabase credentials
3. Add Resend API key (get free at resend.com)

See `ENV_SETUP_GUIDE.md` for details.

### Step 2: Install & Run (1 min)
```bash
cd /Users/deepak/auth-app/dental-crm
npm install
npm run dev
```

### Step 3: Test (2 min)
1. Open http://localhost:3000
2. Click "Sign Up"
3. Create your practice
4. Complete onboarding
5. Explore your new CRM!
