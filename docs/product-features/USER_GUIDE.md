# User Guide - Dental CRM

## Getting Started

### First Login
1. Navigate to your CRM URL
2. Sign in with your credentials
3. Complete onboarding wizard (if first time)

### Dashboard Overview
The dashboard shows:
- Key metrics (revenue, deals, contacts)
- Recent activity
- Upcoming tasks
- Quick actions

## Core Features

### Contacts Management
**Creating a Contact:**
1. Click "New Contact" button
2. Fill in required fields (name, email, phone)
3. Add optional details
4. Click "Save"

**Editing a Contact:**
1. Find contact in list
2. Click to open profile
3. Click "Edit"
4. Make changes
5. Save

### Deal Pipeline
**Creating a Deal:**
1. Go to Pipeline
2. Click "+ New Deal"
3. Select contact
4. Choose pipeline and stage
5. Enter deal value
6. Save

**Moving Deals:**
- Drag and drop between stages
- Or use dropdown to change stage

### Tasks
**Creating a Task:**
1. Go to Tasks
2. Click "+ New Task"
3. Fill details (title, type, due date)
4. Assign to team member
5. Save

**Keyboard Shortcuts:**
- `Cmd+N` - New task
- `j` - Next task
- `k` - Previous task
- `x` - Complete task

### Marketing Campaigns
**Creating a Campaign:**
1. Go to Marketing → Campaigns
2. Click "New Campaign"
3. Choose channel (Email/SMS/WhatsApp)
4. Design content
5. Select audience
6. Schedule or send

### Analytics
Access insights:
1. Go to Analytics
2. Choose dashboard (Executive/CRM/Marketing)
3. Apply date filters
4. Export reports
