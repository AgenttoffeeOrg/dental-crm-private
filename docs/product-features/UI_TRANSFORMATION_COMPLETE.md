## 🎓 **FOR YOUR TEAM**

### **To Apply to New Features:**
1. Use refined components (`Button`, `Card`, `Input`, etc.)
2. Import formatting: `import { format } from '@/lib/formatting'`
3. Format all numbers: `format.number(1234)` → "1,234"
4. Format currency: `format.currency(12345.67)` → "$12,345.67"
5. Use proper pluralization: `format.pluralize(5, 'item')` → "5 items"
6. Add loading states: `<LoadingState message="..." />`
7. Add empty states: `<EmptyState icon={...} title="..." />`
8. Follow spacing guidelines: `space-y-8`, `gap-5`, `p-5`
