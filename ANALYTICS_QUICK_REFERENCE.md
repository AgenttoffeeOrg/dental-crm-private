## 🎯 Key Metrics Explained

### **Business Health Score (0-100)**
Weighted average of 5 components:
- Revenue Growth (30%)
- Pipeline Health (25%)
- Activity Level (20%)
- Win Rate (25%)

**90-100:** Excellent  
**70-89:** Good  
**50-69:** Average  
**<50:** Needs Improvement

### **ROI (Return on Investment)**
```
ROI = ((Revenue - Cost) / Cost) × 100%
```
**>100%:** Profitable  
**0-100%:** Breaking even  
**<0%:** Losing money

### **CAC (Customer Acquisition Cost)**
```
CAC = Total Marketing Spend / Number of Customers Acquired
```
Lower is better!

### **LTV (Lifetime Value)**
```
LTV = Average Deal Value × Deals Per Customer
```
Higher is better!

### **Win Rate**
```
Win Rate = (Deals Won / Total Deals) × 100%
```
**>60%:** Excellent  
**40-60%:** Good  
**<40%:** Needs work

## 🚀 Quick Tips

### **To Find Top Opportunities:**
1. Go to **CRM Analytics** tab
2. Click **Forecasting** view
3. Look at win probability list
4. Focus on deals >70% probability

### **To Identify Problems:**
1. Go to **Executive** tab
2. Check AI Insights panel
3. Look for red "Risk" cards
4. Follow recommended actions

### **To Optimize Marketing:**
1. Go to **Marketing** tab
2. Check **Channels** view
3. Compare engagement funnels
4. Invest more in highest ROI channel

### **To Improve Retention:**
1. Go to **Cohort** tab
2. Check retention table
3. Find where retention drops (red cells)
4. Launch re-engagement campaigns
