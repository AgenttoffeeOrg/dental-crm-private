## 🎓 HOW TO USE (Quick Guide)

### **Create an Email Campaign:**
1. Go to `/marketing/campaigns/create`
2. Select "Email" channel
3. Use drag-drop builder to design email
4. Choose audience segment
5. Schedule or send now
6. Track performance in analytics

### **Build Automation:**
1. Go to `/marketing/journeys`
2. Click "New Journey"
3. Drag actions to canvas
4. Configure triggers and actions
5. Activate journey
6. Watch contacts flow through

### **Post to Social Media:**
1. Go to `/marketing/social-media/create`
2. Select platforms (FB, IG, TikTok, etc.)
3. Write content, add hashtags, upload media
4. Schedule or publish now
5. Track engagement

### **Import Contacts:**
1. Go to `/marketing/audiences`
2. Click "Import CSV"
3. Upload file
4. Map fields
5. Import contacts
