## 🏥 **6 Pre-Configured Dental Pipeline Templates**

### 💎 **High-Value Treatment**
For premium treatments like implants, full mouth reconstructions (£5,000+)

**9 Stages:** Initial Consultation → Treatment Planning → Insurance Verification → Financial Approval → Pre-Treatment → In Progress → Follow-up → Completed/Lost

**Best for:** Implants, full mouth reconstructions, complex cosmetic work

---

### 🚨 **Emergency Treatment**
Fast-track for urgent cases needing immediate attention

**8 Stages:** Emergency Received → Triage → Scheduled (24hrs) → In Treatment → Post-Care → Follow-up → Resolved/Referred

**Best for:** Toothaches, broken teeth, infections, trauma

---

### 👥 **General Practice**
Standard routine care pipeline (set as default)

**9 Stages:** New Inquiry → Contacted → Appointment Scheduled → Consultation → Treatment Proposed → Accepted → In Progress → Completed/Lost

**Best for:** Checkups, cleanings, fillings, routine work

---

### 🦷 **Orthodontics**
Long-term tracking for braces and alignment

**9 Stages:** Initial Consult → Records & Diagnosis → Plan Presented → Financial Agreement → Appliance Placed → Active Treatment → Retention → Complete/Lost

**Best for:** Braces, Invisalign, retainers

---

### ✨ **Cosmetic Dentistry**
Elective aesthetic procedures

**9 Stages:** Consultation Request → Smile Analysis → Design Presentation → Quote Sent → Approved → Scheduled → Completed → Follow-up/Lost

**Best for:** Veneers, whitening, smile makeovers

---

### 🤝 **Referral Network**
Manage specialist referrals

**7 Stages:** Referral Received → Records Reviewed → Patient Contacted → Scheduled → Complete → Report Sent → Closed

**Best for:** Referrals from/to other dentists

## 🎯 **How to Use the Interface (HubSpot-Style)**

### **Step 1: Select or Create a Pipeline**

Click the pipeline dropdown (top left):
```
┌─────────────────────────────────┐
│ 🔄 General Practice ▼          │
└─────────────────────────────────┘
```

Options:
- **Your Pipelines** - Switch between existing pipelines
- **Create Custom Pipeline** - Build from scratch
- **Templates** - 6 pre-configured options

---

### **Step 2: Switch Views**

Toggle between Board and List view (top right):
```
[🎯 Board] [📋 List]
```

**Board View** - Kanban-style drag & drop
**List View** - Table format with sortable columns

---

### **Step 3: Edit Pipeline**

Click "Edit Pipeline" button:
- Add/remove stages
- Rename stages
- Reorder stages
- Delete pipeline

---

### **Step 4: Create Deals**

Click "+ New Deal" - opens clean creation form with:
- Duplicate prevention
- Smart contact selection
- Automatic pipeline/stage assignment
- Treatment tags
- Deal value tracking

---

## 🔗 **Everything Links to Patients!**

### **From Board View:**
- Click deal card → Full deal details
- Click patient name → Patient profile
- Hover card → Quick actions appear

### **From List View:**
- Click row → Deal details
- Click patient name (blue) → Patient profile
- Click "View" button → Deal details

### **From Deal Details:**
- Click patient name → Patient profile
- See all patient deals across ALL pipelines
- Navigate between deals

### **From Patient Profile:**
- See ALL deals in ALL pipelines
- Click any deal → Opens in context
- Create new deal in any pipeline

## 🚀 **Quick Start Guide**

### **First Time Setup:**

1. Go to **Pipeline** in sidebar
2. Click pipeline dropdown
3. Select a template (try "General Practice")
4. Click "Create from Template"
5. Customize stages if needed
6. Click "Create Pipeline"

### **Daily Use:**

1. Select your pipeline from dropdown
2. Toggle to Board or List view
3. Drag deals between stages (Board view)
4. Click patient names to see full profiles
5. Create new deals with "+ New Deal"
