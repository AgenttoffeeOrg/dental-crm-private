    SCENARIO 1: Update Routing Rules & Re-route All Deals
    ──────────────────────────────────────────────────────

    Problem: Admin updates treatment tag mappings and wants to
             apply new rules to all existing deals.

    Solution:
    1. Open Settings → Treatment Routing → Bulk Operations
    2. Apply filters (or select all)
    3. Enable "Dry Run Mode"
    4. Click "Preview Changes"
    5. Review results
    6. Disable dry run
    7. Execute live re-routing
    8. Export results for audit


    SCENARIO 2: Migrate from Legacy System
    ───────────────────────────────────────

    Problem: Practice has old treatment tags in localStorage
             from previous version.

    Solution:
    1. Open Settings → Treatment Routing → Migration Wizard
    2. Wizard detects 15 tags in localStorage
    3. Select tags to migrate
    4. Preview shows 12 new, 3 conflicts
    5. Create backup (downloads JSON)
    6. Execute migration
    7. 12 tags migrated successfully
    8. localStorage cleaned up


    SCENARIO 3: Identify & Fix Mis-routed Deals
    ────────────────────────────────────────────

    Problem: Admin suspects some deals are in wrong pipelines
             and wants to identify and fix them.

    Solution:
    1. Open Settings → Treatment Routing → Deal Audit
    2. Click "Run Audit"
    3. Wait for completion (shows progress)
    4. Review summary: 45 of 500 mis-routed
    5. Filter by "High Priority"
    6. Review 12 critical mis-routings
    7. Click "Fix" on each or use bulk re-route
    8. Export report for management
