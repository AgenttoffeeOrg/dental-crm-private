## 🎯 Quick Actions

### Create a Campaign (3 Clicks)
1. Click "New Campaign" button
2. Fill in details (channel, audience, content)
3. Hit "Create & Send"

### Use the Command Palette
1. Press `Cmd+K` (or `Ctrl+K` on Windows)
2. Type what you want
3. Hit Enter

### Build an Audience
1. Go to Audiences → "Create Segment"
2. Add filter rules
3. See real-time count → Save
