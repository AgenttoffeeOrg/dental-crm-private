## 🚀 **HOW TO USE EVERYTHING:**

### **1. View Deal Intelligence:**
```bash
1. Go to http://localhost:3000/pipeline
2. Every deal card shows mini-dashboard
3. See likelihood score, sentiment, talks
4. Click deal → See full dashboard
5. See next best action suggestion
```

### **2. Edit an Activity:**
```bash
1. Open any deal
2. Go to Activities tab
3. Find any logged activity
4. Click Edit button (✏️)
5. Modify subject or notes
6. Click Save
7. ✅ Updates instantly!
```

### **3. Edit a Treatment Rule:**
```bash
1. Go to Settings → Auto-Categorization
2. Find "Dental Implants" card
3. Click Edit (✏️)
4. Change min value from £3,000 to £5,000
5. Click "Update Treatment Rule"
6. ✅ Saves instantly!
```

### **4. Set Role Permissions:**
```bash
1. Go to Settings → Roles
2. Click "Permissions" on any role
3. Modal opens with 10 categories
4. Click "💼 Deals" to expand
5. Toggle permissions ON/OFF
6. Click "Save Changes"
7. ✅ Permissions saved!
```

### **5. Test Reload Persistence:**
```bash
1. Go to any pipeline
2. Press Cmd+R
3. ✅ Stays on same pipeline!

4. Go to Settings → Roles tab
5. Press Cmd+R
6. ✅ Stays on Roles tab!
```

## 📊 **WHAT EACH FEATURE DOES:**

### **Deal Intelligence Scoring:**

**Calculates:**
- Base score: 50%
- +20% if positive sentiment
- +15% if contacted in last 3 days
- +10% if many interactions
- -20% if negative sentiment
- -20% if cold (>14 days)

**Result:**
- 0-100% likelihood score
- Health status (Excellent/Good/Fair/Poor/Critical)
- Next best action based on all factors
